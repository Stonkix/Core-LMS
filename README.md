# Corporate LMS (Learning Management System)

Современная платформа для организации корпоративного обучения, обмена знаниями и отслеживания прогресса сотрудников. Проект построен на базе **Django 6.0**, ориентирован на гибкость и простоту управления образовательным контентом.

---

## 🚀 Основные возможности

### Управление пользователями
* **Кастомная модель пользователя**: Расширенные профили сотрудников с дополнительными полями (телефон, должность).
* **Система ролей**: Разграничение прав доступа (Администратор, Преподаватель, Студент).
* **Личный кабинет**: Индивидуальная страница профиля с историей обучения.

### Образовательный контент
* **Курсы и модули**: Иерархическая структура учебных материалов.
* **Разнообразный контент**: Поддержка текстовых лекций, видеоматериалов и вложений, конструктор создания курсов.
* **Управление из админки**: Удобный интерфейс Django Admin для создания учебных групп и пользователей.

### Функционал системы
* **Авторизация**: Безопасный вход и выход из системы.
* **Адаптивный дизайн**: Корректное отображение на мобильных устройствах и десктопах.

---

## 🛠 Технологический стек

* **Backend**: Python 3.12, Django 6.0
* **Database**: SQLite (для локальной разработки), готова к миграции на PostgreSQL.
* **Environment**: Встроенные механизмы управления сессиями и аутентификацией Django.

---

## 🛠 Как запустить локально
1. Клонировать репозиторий
2. Создать виртуальное окружение: `python -m venv .venv`
3. Активировать его и установить зависимости: `pip install -r requirements.txt`
4. Выполнить миграции: `python manage.py migrate`
5. Запустить сервер: `python manage.py runserver`
